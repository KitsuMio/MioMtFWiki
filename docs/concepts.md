# 概念与术语

## 性别相关基础概念

::: info 性别认同

一个人内心认同自己是什么性别。

不取决于外表、穿着、身体特征、性取向、是否 HRT、是否手术或能否 pass。

:::

::: info 性别表达

一个人通过穿着、发型、言行举止展现出来的性别风格。可以是女性化、男性化或中性化，和性别认同是两件独立的事——表达女性化不代表认同为女性。

:::

::: info 性取向

一个人喜欢什么性别的人，与自己的性别认同无关。跨性别者的性取向同样多样，不因为是跨性别就限定喜欢某一性别。

性取向描述“喜欢谁”，性别认同描述“自己是谁”，两者没有任何关系。

:::

::: info 出生时被指派性别（AGAB）

一个人出生时，被外界非自愿指定为的性别。

- AMAB：出生时被指派为男性
- AFAB：出生时被指派为女性

出生时被指派性别描述的是一次出生分类，不代表一个人的实际性别。

:::

::: info 顺性别（Cisgender）

性别认同与出生时被指派性别一致的人。

:::

::: info 跨性别（Transgender）

性别认同与出生时被指派性别不一致的人。

:::

::: info GD（Gender Dysphoria）

性别不安/性别焦虑。

指身体特征、社会角色、称呼或他人认知与自身性别认同不一致时产生的心理痛苦。

:::

::: info "生理性别"

"生理性别"不是一个准确的性别概念。

人体中不存在一个可以直接读取、天然统一并决定性别的"生理性别"属性。染色体、性腺、外生殖器、内生殖结构、激素水平、第二性征，这些维度各自独立发育，彼此并不天然对应。每个维度自身的表现也是连续的，不是只有两种状态。"男性身体""女性身体"是在这些连续谱系上人为划出的两个区间，而不是身体自带的两个格子。

实际使用中，这个词表达的是说话者根据自己选择的身体标准，对他人作出的性别分类。

使用"生理性别"时，首先需要回答：

- 指染色体吗？
- 指出生时的外生殖器吗？
- 指当前生殖结构吗？
- 指性腺吗？
- 指激素状态吗？
- 指第二性征吗？
- 指外貌吗？
- 指是否进行 SRS 吗？
- 还是只是在重复出生时被指派性别？

不同标准会得到不同结论。

同一个长期进行 HRT 的跨女，有人依据染色体称其为"生理男性"，有人依据激素状态和第二性征称其为"生理女性"；完成 SRS 后，仍然有人承认其"生理性别改变"，也有人坚持没有改变。判断结果随着判断者采用的标准变化，说明这里存在的是主观分类，而不是一个独立存在的生理事实。

这个词最常见的用法，是把本来连续、多维的身体特征压缩成非黑即白的标签，再把出生时依据外生殖器作出的分类，或者对染色体的分类，包装成不可改变的"生理事实"。

身体特征是真实存在的，"生理性别"则是对这些特征作出的主观性别判断。需要讨论身体时，应直接使用"染色体""激素水平""生殖结构""第二性征"或"出生时被指派性别"等准确表述。

:::

## 跨性别方向分类

::: info MtF / 跨女

出生时被指派为男性、性别认同为女性的跨性别者。

MtF 是女性，不是男娘或女性化男性。

是否 HRT、是否 SRS、是否出柜、是否具有女性化表达、是否 pass，都不影响 MtF 身份成立。

:::

::: info FtM / 跨男

出生时被指派为女性、性别认同为男性的跨性别者。

:::

::: info Non-binary（非二元）

性别认同不属于男性或女性的人。

- MtX：出生时被指派为男性，但性别认同不属于男性或女性
- FtX：出生时被指派为女性，但性别认同不属于男性或女性

:::

## 容易混淆但不是跨性别的身份

::: info CD（Crossdresser，异装者）

穿着另一性别服装的人，性别认同与出生指派性别一致。

穿衣是表达或爱好，不是性别认同。

:::

::: info 男娘 / 伪娘

来源于日语“男の娘”，指外表、穿着、声音或角色形象女性化的男性。

男娘文化来自日本二次元文化，强调可爱、少女感、反差感以及男性角色的女性化。

性别认同为男性或非二元（MtX），男娘不是 MtF。

:::

::: info 雌堕

色情作品和性幻想中的一个题材。

指男性角色因性快感、调教、臣服，被塑造成女性化、色情化或顺从的男性形象，但仍然是男性。雌堕经常与男娘题材同时出现。

雌堕描述性叙事中的女性化的男性，不是角色的性别认同变为女性，也不是 MtF 身份。

:::

::: info 药娘 / yn / xyn

通常指正在或已经进行 HRT 的 MTF，但偶尔也会用来指代服用雌激素的 MtX 或男娘。

总之，只要指派性别不为女，但服用雌激素，就可以被称为药娘。

这不是一个能完整体现跨性别女性身份的词语。

MtF 不都是药娘，药娘不一定是 MtF。

:::

## HRT 相关 {#hrt-related}

::: info HRT（Hormone Replacement Therapy）

激素替代疗法。

通过药物调整体内激素水平，使身体特征更接近自己认同的性别。

MtF HRT 以雌二醇为核心，通常还会配合抗雄激素。

HRT 是身体层面的性别肯定医疗手段，不是跨性别身份成立的条件。是否进行 HRT 不影响一个人是不是跨性别。

:::

::: info GAHT（Gender-Affirming Hormone Therapy）

性别肯定激素治疗。

GAHT 是比 HRT 更准确的现代医学术语。HRT 原意为“激素替代治疗”，范围更广，也可用于绝经期激素治疗、性腺功能减退等情况；而 GAHT 专门强调其性别肯定目的。

在跨性别社群中，HRT 仍然是最常用的习惯称呼，因此 MtF HRT 与 MtF GAHT 在多数语境下通常指同一件事。

:::

::: info 糖 / 吃糖

“糖”泛指 HRT 药物，“吃糖”指使用 HRT 药物。

这是社区常用隐语，用于不方便直接提及 HRT 的场合。

:::

::: info 补佳乐 / 补

补佳乐是一种雌二醇药物，“补”是社区中的简称。

:::

## 医疗与法律文件

::: info 小证

写有性别不安、性别认同相关诊断或治疗意见的病历、诊断书。

常用于支持开始 HRT。具体要求和效力由医院、医生和使用场景决定。

:::

::: info 大证

正式的性别认同障碍、性别不安或相关诊断证明。

用于申请 SRS 等医疗项目，具体名称、要求和效力由医院与地区规定。

:::

::: info SRS（Sex Reassignment Surgery）

性别重置手术。

SRS 是改变生殖结构的性别肯定医疗手段，不是跨性别身份成立的条件。做不做手术不影响一个人是不是跨性别。

:::

## pass 与身份处境

::: info pass

指一个人的性别表达在他人（尤其陌生人）视角下，被自然识别为自己认同的性别，而没有被识别为指派性别。

是他人识别和性别表达层面的结果，不是身份是否真实的判断标准。

:::

::: info 鉴跨

指他人根据一个人的外在特征，对其是否为跨性别者进行推测或判断。

这种行为通常带有冒犯性，在社区内不受欢迎。

:::

::: info RLE（Real-Life Experience）

以自己认同的性别在现实生活中持续生活，包括使用对应姓名、称呼、穿着和社会身份。

RLE 描述社会生活状态，不决定性别认同，也不是 MtF 身份成立的必要条件。

:::

::: info 深柜

跨性别者长期隐藏自己的跨性别身份，并以指派性别身份或社会默认身份生活、表达自己。

例如：一名 MtF 以“男性”身份自称，对外不公开自己的跨性别身份。

:::

::: info 反向深柜

跨性别者隐藏自己的跨性别身份，并主动以符合性别认同的身份生活，但不公开自己是跨性别者。

例如：一名 MtF 以“女性”身份自称，并以顺性别女性身份融入社会，不主动透露自己的跨性别经历。

:::

::: info 出柜

主动向他人公开自己的跨性别身份。

:::

::: info 爆柜

跨性别身份在本人没有主动选择或没有做好准备时被他人发现、传播或公开。

:::

## 家庭与处境分类（社区俗称）

::: info 家长党

取得家长理解和支持的跨性别者。

:::

::: info 家暴党

因跨性别身份在家庭中遭受暴力、威胁、控制或强制干预的跨性别者。

:::

::: info 年龄党

在青春期较早阶段就开始 HRT 的跨性别者，通常意味着身体可塑性更高。

:::

::: info 天赋党

先天身体条件较接近自己认同性别，较容易通过 HRT、声音训练或表达达到女性化效果的跨性别者。

相关身体条件包括骨骼、身高、声音、面部特征、体毛和体脂分布等。

:::

::: info 天残党

先天身体条件与自己认同性别差距较大，女性化过程受到更多身体条件限制，需要更多其他手段（手术、声音训练等）辅助。

:::

## 社会立场分类

::: info 友跨

支持跨性别者，承认其性别认同，尊重其称呼、身份、身体自主和同等权利的立场。

:::

::: info 反跨

否定、贬低或排斥跨性别者的性别认同、身份、表达、医疗需求或平等权利的立场。

以出生时被指派性别、染色体、生殖器或所谓“生理性别”否定跨性别者实际性别，属于常见反跨论述。

:::

---

## 社群黑话

::: info 开除跨籍

社群内的非正式说法，指某些人以特定标准（例如"是不是在 HRT""够不够 pass""是否符合某种刻板印象"等）否认另一个人或某个群体的跨性别身份。理由多种多样，有时围绕 HRT、手术与否，有时围绕表达方式或其他原因。这种行为本身在社群内存在争议。

:::
