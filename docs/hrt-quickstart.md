# 简单明确的用药方案

::: warning 在继续之前

这篇文章是给「不想系统学习 HRT，只想先知道常见方案」的人准备的。

它会尽可能把内容压缩到最少，但代价是省略了大量原理、个体差异和剂量调整逻辑。

如果你有时间，仍然建议先阅读 [HRT入门](./hrt-start)。知道自己为什么这样用药，永远比记住一个方案更重要。

:::

::: tip 关于抗雄

如果抗雄压制不理想，不要盲目增加抗雄药剂量，优先把雌二醇调整到目标范围。[^hembree2017]

:::


### 方案 A

这是本站最推荐的组合。凝胶避开口服首过代谢，螺内酯不增加 CPA 特有的泌乳素升高和累计剂量相关脑膜瘤风险。[^soc8]

- **药物组合**：螺内酯 (安体舒通) + 雌二醇凝胶 (爱斯妥/Estrogel)
- **用法用量**：
    - **螺内酯**：每天 `100 ~ 300 mg`（分两次口服）。[^soc8]
    - **雌二醇凝胶**：每日一次，`1 ~ 2 计量尺` 或 `2 ~ 4 泵`（取决于包装类型），涂抹于大腿内侧或手臂。[^soc8][^oestrogelmeasure][^oestrogel]
- **副作用**：螺内酯是利尿剂，会增加排尿并可能导致口渴、脱水、低血压和疲劳，也可能引起高钾血症，使用期间检查血钾和肾功能；凝胶可能导致乳房胀痛、头痛和涂抹部位瘙痒、皮疹或刺激，未干前可能经皮肤接触转移给他人。[^hembree2017][^aldactone][^estrogel]

不要自行补钾或使用含钾盐替代品。正常饮食不需要一律禁食高钾食物；肾功能异常或已经高钾时按医嘱限制。[^aldactone]

### 如果是凝胶，先分清楚你拿到的是哪种

![stradiol-gel-pump-vs-tube](images/estradiol-gel-pump-vs-tube.png)

凝胶应薄涂在清洁、干燥、完整的大腿内侧或手臂皮肤；约 5 分钟干燥后再穿衣服，涂后至少 1 小时避免清洗、使用其他皮肤产品或让他人直接接触涂抹处。[^oestrogel]

### 方案 B

这是本站第二推荐的方案。只使用凝胶，通过持续的雌二醇暴露抑制 LH 和睾酮，不使用 CPA 或螺内酯。足量、连续的透皮 17β-雌二醇可以抑制睾酮生成。[^esi2025]

- **药物组合**：仅雌二醇凝胶 (爱斯妥/Estrogel)
- **用法用量**：每日一次，约 `3 mg 雌二醇`；常见包装对应 `2 计量尺` 或 `4 泵`，涂抹于大腿内侧或手臂。[^soc8][^oestrogelmeasure][^oestrogel]
- **怎么判断成功**：稳定使用约 3 个月后检查 E2 和 T；达到 **E2 100～200 pg/mL、T <50 ng/dL** 时，不需要再加抗雄药。[^hembree2017][^soc8]
- **如果 T 没压住**：不要继续凭泵数盲目加量，改用方案 A 或方案 C。
- **副作用**：可能出现乳房胀痛、头痛和涂抹部位瘙痒、皮疹或刺激；凝胶未干前可能经皮肤接触转移给他人。[^estrogel]

### 方案 C

色普龙抗雄效果强，雌二醇凝胶避开口服雌激素的首过代谢。

- **药物组合**：醋酸环丙孕酮（色普龙） + 雌二醇凝胶 (爱斯妥/Estrogel)
- **用法用量**：
    - **CPA**：每天一次，`10 ~ 12.5 mg`（口服）。[^soc8][^defreyne2021]
    - **雌二醇凝胶**：每日一次，`1 ~ 2 计量尺` 或 `2 ~ 4 泵`（取决于包装类型），涂抹于大腿内侧或手臂。[^soc8][^oestrogelmeasure][^oestrogel]
- **副作用**：CPA 可能导致泌乳素升高、疲劳、情绪低落和肝功能异常，脑膜瘤风险随累计剂量增加；凝胶可能导致乳房胀痛、头痛和涂抹部位瘙痒、皮疹或刺激，未干前可能经皮肤接触转移给他人。应使用最低有效剂量的 CPA，10 mg 的睾酮抑制效果与更高剂量相当。[^wilson2020][^defreyne2021][^ema2020][^estrogel]

### 方案 D

常见的经典方案，药物获取方便、使用简单、抗雄效果强。舌下雌二醇峰值较高，因此应分次含服；不要因为一次化验结果而增加 CPA。

- **药物组合**：醋酸环丙孕酮 (色普龙) + 雌二醇片 (补佳乐)
- **用法用量**：
    - **CPA**：每天一次，`10 ~ 12.5 mg`（口服）。[^soc8][^defreyne2021]
    - **补佳乐**：每天 `2 ~ 6 mg`（分两次**舌下含服**）。[^soc8][^doll2022]
- **副作用**：CPA 可能导致泌乳素升高、疲劳、情绪低落和肝功能异常，脑膜瘤风险随累计剂量增加；舌下雌二醇可能导致乳房胀痛、头痛和恶心，并形成较高峰值和更明显的浓度波动。[^wilson2020][^doll2022][^ema2020][^soc8]

### 方案 E

这种组合不使用 CPA，适合希望避开 CPA 特有副作用、同时能够监测血钾和肾功能的人。

- **药物组合**：螺内酯 (安体舒通) + 雌二醇片 (补佳乐)
- **用法用量**：
    - **螺内酯**：每天 `100 ~ 300 mg`（通常分两次口服）。[^soc8]
    - **补佳乐**：每天 `2 ~ 6 mg`（分两次**舌下含服**）。[^soc8][^doll2022]
- **副作用**：螺内酯是利尿剂，会增加排尿并可能导致口渴、脱水、低血压和疲劳，也可能引起高钾血症；舌下雌二醇可能导致乳房胀痛、头痛和恶心，并形成较高峰值和更明显的浓度波动。[^aldactone][^doll2022][^soc8]

不要自行补钾或使用含钾盐替代品。[^aldactone]
